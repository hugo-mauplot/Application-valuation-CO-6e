Enregistrer la configuration d’évaluation

Cette action mémorise tous les paramètres actuels du niveau actif :

  • le format d’évaluation sélectionné ;
  • les parcours, variantes et balises associées ;
  • les codes et niveaux des balises ;
  • la durée, les pénalités et le barème appliqué ;
  • les cartes et les autres réglages de la séance.

Les participants, les projets individuels, les horaires, les tentatives et les résultats ne sont pas enregistrés. La configuration de l’autre niveau reste inchangée.

Mode entraînement

Reprenez la séance en cours ou appliquez une séance enregistrée. Une séance appliquée démarre sans classe, participant, résultat ni état de pose.

Inventaire des balises de l’établissement

Indiquez le nombre de balises disponibles. Après validation, le tableau complet s’affichera pour renseigner les numéros, les grilles de codes et les pictogrammes.

Créer un parcours

Définissez l’identité, la structure et les niveaux du parcours. Vous associerez ensuite chaque numéro de la carte à une balise du collège.

Une ligne par variante : tous les numéros de la carte, séparés par des virgules. Exemple : 3, 1, 2.

Premières balises différentes par variante ; répartition équilibrée si les variantes sont plus nombreuses que les balises. Enregistrez pour appliquer aux fiches et au mode Terrain.

Niveaux des balises et points associés

Choisissez le nombre de niveaux : N1, N2, N3… sont créés automatiquement. Associez ensuite de 1 à 100 points à chacun.

Configurer les balises

Pour chaque numéro visible sur la carte des élèves, associez une balise physique du collège et choisissez son niveau. Le code attendu dépend du code A1–E6 attribué à l’élève ou au groupe.

Codes de la balise

Recopiez le tableau physique de cette balise : 5 colonnes A à E et 6 lignes 1 à 6. Laissez une case vide si aucun code n’est inscrit.

Les codes copiés peuvent être vérifiés avant leur enregistrement.

Guide de prise en main

Tutoriel détaillé

Les étapes indispensables pour préparer l’application et suivre les participants sur le terrain.

⌖

1. Avant la séance

Préparer le matériel et les réglages
Inventorier les balises

Dans Balises, ouvrez « Inventaire des balises de l’établissement », indiquez le nombre de balises disponibles et renseignez leurs numéros et leurs codes.

Créer les parcours

Dans Balises, créez chaque parcours avec son nom, sa couleur, son nombre de balises, ses variantes et ses niveaux.

Associer les balises

Pour chaque numéro visible sur la carte, choisissez la balise physique du collège correspondante, son niveau et le code attendu pour chaque variante.

Régler la séance

Dans Réglages, définissez la durée et les paramètres de l’épreuve. Créez également vos classes si vous souhaitez sélectionner les élèves dans une liste.

Enregistrer une configuration

Enregistrez les réglages comme configuration d’évaluation ou comme séance d’entraînement afin de pouvoir les réutiliser.

Contrôler la pose

Dans Balises, utilisez « Pose — Dépose » et cochez chaque balise installée avant le début de la séance.

À retenir : un numéro sur la carte peut correspondre à un autre numéro dans l’inventaire du collège. L’association réalisée dans le parcours permet à l’application de vérifier le bon code.
▶

2. Pendant la séance

Ajouter et suivre les participants
Choisir le type de séance

Dans Terrain, activez le mode Entraînement ou Évaluation et appliquez, si besoin, une configuration déjà enregistrée.

Ajouter les participants

Dans Élèves, choisissez Individuel, Duo ou Trio, sélectionnez la classe, ajoutez les participants et attribuez leur parcours.

Déclencher le début de l’épreuve

Utilisez « Début d’épreuve » dans la fiche d’un participant ou déclenchez le début pour tous. Le chronomètre général commence.

Enregistrer un retour

À chaque retour, ouvrez Terrain, sélectionnez le participant et la balise, saisissez le code puis enregistrez la tentative. L’heure du retour est enregistrée automatiquement.

Donner le départ suivant

Le participant apparaît dans « Dernières tentatives ». Appuyez sur « Départ suivant » lorsqu’il repart : une nouvelle heure de départ est enregistrée.

Terminer l’épreuve

Lorsqu’il ne repart plus, appuyez sur « Fin d’épreuve » dans sa fiche. Le chronomètre s’arrête et son résultat définitif est calculé.

Consulter les résultats

Ouvrez Résultats pour retrouver les points, les erreurs, le temps et, en mode évaluation, la note.

Début d’épreuve→ Tentative→ Départ suivant→ Tentative→ Fin d’épreuve
Important : enregistrer une tentative signale un retour intermédiaire. Seul « Fin d’épreuve » arrête définitivement le chronomètre.
